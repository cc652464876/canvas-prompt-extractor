# 开发辅助

本目录集中保存开发、测试和验收所需的辅助内容。

- **测试代码**：自包含单元测试和脱敏、合成夹具。
- **验收工具**：测试入口、Electron 验收脚本、品牌检查项和主题资料导入工具。
- **验收记录**：报告、截图、测试日志、合成导出及 v1.1 原文件校验清单。
- **开发文档**：开发流程、品牌接入与架构说明、说明图片。
- **工具配置**：ESLint 和 Prettier 配置；由 package.json 命令明确指定。

请在 v1.2 项目根目录运行 `pnpm test`、`pnpm check`、`pnpm format:check` 和各项 `pnpm verify:*`。普通启动仍使用根目录 CMD、launch.ps1 及 scripts/start.cjs；scripts/build.cjs 也会在启动时运行，因此这两个脚本保留原位。

package.json、pnpm-lock.yaml、pnpm-workspace.yaml、.gitignore 和 .gitattributes 保留在根目录，遵循工具发现和作用范围约定。README、使用说明、版本说明和账号安全与隐私说明保留在根目录，便于使用者查看。node_modules、src、build 和 .runtime 仍按原职责保留。

中文目录不会改变测试规则。文件引用随本次迁移更新，测试入口把绝对文件路径逐项传给 Node，不依赖 shell 展开通配符；验收输出通过 src/app-paths.cjs 定位。不要再手动移动辅助子目录，否则仍需同步修改配置与引用。

现有 PowerShell 启动脚本无需嵌入这些中文目录名。本次未修改其编码；将来如向 Windows PowerShell 5.1 脚本加入中文字符串，应使用兼容该版本的 UTF-8 BOM 编码。

验收入口依赖本目录的脚本和测试夹具；保留它们便于后续升级检查。验收记录不包含应当用于正式登录的账号资料。
