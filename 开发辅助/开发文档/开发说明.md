# 开发与验证 · v1.3

## 环境

Windows x64，Node.js >=22.13（建议 24）。依赖版本由 package.json 和 pnpm-lock.yaml 固定。运行 `pnpm install --frozen-lockfile`；pnpm-workspace.yaml 仅放行 Electron 和 esbuild 的安装脚本，使用 `nodeLinker: hoisted` 避免 Windows Junction 的绝对路径，使用 `extendNodePath: false` 避免命令包装脚本保存旧路径。旧安装目录需在关闭程序后移除该副本的旧 node_modules，再安装，避免遗留旧链接和命令包装脚本。

运行 `pnpm start` 或根目录 CMD。启动会先构建本版本；程序不会读取旧便携 EXE。后台启动日志在 `.runtime/startup.log` 与 `.runtime/startup-error.log`。

CMD 优先使用 `runtime/node.exe`。完整复制 `src/`、`scripts/`、`开发辅助/验收工具/`（验证时需要）、`node_modules/`、`runtime/`、`tools/` 和根目录配置及启动文件，可在兼容的 Windows x64 机器离线启动。分享副本应排除 `.runtime/profile` 等账号资料。依赖安装好且 Electron 二进制完整后，启动不需要 pnpm；开发检查仍需要 pnpm 或等效命令。

## 检查

- `pnpm build`：esbuild 构建到 build/，验证字体及许可证。
- `pnpm check`：未定义变量与无效引用检查。
- `pnpm format:check`：检查源码、辅助工具、测试和 ESLint 配置格式。
- `pnpm test`：先构建再运行自包含单元测试。
- `pnpm verify:ui`：真实 Electron 中的合成三品牌提取、保存、重载、旧事件隔离及布局，包括 RHTV 的作品详情只读入口和直接画布。
- `pnpm verify:text`、`pnpm verify:readers`：正文、关联、导航、预览和字体。
- `pnpm verify:accounts`、`pnpm verify:account-startup`：各品牌账号 DOM 与窗口复用；后者验证设置中的独立网站访问、持久化会话复用及不存在登录状态监控。
- `pnpm verify:local-project`、`pnpm verify:browser-reset`、`pnpm verify:deadline`、`pnpm verify:cleanup`：本地文件、浏览器资料、取消/超时和浮层资源释放。
- `pnpm verify:themes`：主题回归，可用 `-- --palettes=default,codex` 缩小调试范围。
- `pnpm verify:preservation`：本机有相邻 v1.2 目录及升级前清单时，复核其原文件哈希；仅下载 GitHub 源码时无需运行此本机保留检查。
- `pnpm verify:transfer`：复制到临时中文空格目录，移除 PATH 中的 Node/pnpm，使用随目录携带的运行时启动并执行 Electron 验证，不复制账号资料。

自包含验证不依赖旧版本私人快照或登录资料。应用验证模式使用临时浏览器 profile，导出只进入本版本 开发辅助/验收记录/projects。正式程序使用本版本独立 .runtime；不要把验证模式资料用于正式登录。

真实平台验证需显式提供链接：`pnpm verify:live -- --verify-input=https://平台作品链接 --verify-visible`。默认不下载；只有指定 `--verify-downloads` 才下载样本。不要将生成、消耗积分或发布操作加入读取验证。

## 文件职责

`tools/exiftool/` 是完整的 Windows x64 随附工具目录，复制项目时必须保留。`src/services/exiftool.cjs` 负责后台常驻进程、参数管道、UTF-8 JSON、超时及退出；`src/image-metadata.cjs` 负责提示词、模型证据、C2PA 处理记录与非标准 PNG 中文解码；`src/services/image-info.cjs` 负责每批最多 32 张的队列、请求合并和每作品 `.图片信息.json` 缓存。缓存以相对文件名、文件大小、修改时间及识别版本判定失效，按批原子保存，读取过程中替换文件会拒绝缓存。缓存不写回原图，不将完整签名二进制或图片像素存入 JSON。

`pnpm verify:image-info` 验证真实内置 ExifTool 的中文 PNG 读取、提示词复制、多结果切换、缓存、未下载状态与图片信息弹窗；测试不依赖私人图片。

src/platforms：品牌元数据、页面注入、解析、账号和素材策略。src/core：格式与完整性约定。src/services：提取任务和媒体访问。src/export：过滤、命名、Markdown。src/ui：视图模型、交互及动态账号入口。开发辅助/验收工具/检查项：Electron 验收。

辅助目录职责见 [目录说明](../说明.md)。测试位于开发辅助/测试代码；ESLint 和 Prettier 配置位于开发辅助/工具配置，由 package.json 明确指定。验收输出统一使用 src/app-paths.cjs 的 verificationPath，测试入口通过 Node 参数数组传递绝对测试文件路径，不依赖 shell 通配符。scripts/ 只保留日常启动必需的 start.cjs 和 build.cjs。

build/ 是生成物，不能直接维护；src/ 不再保留生成脚本副本。没有 package:portable 或 verify:portable 入口。阅读区和布局样式的旧版本文件暂时保留既有覆盖顺序，避免在架构迁移中引入无关视觉变化。

v11-golden.json 来自已有脱敏/合成测试夹具的旧版标准结果，运行测试无需访问 v1.1。它验证参数、引用顺序、文本版本、素材标识和 Markdown 行为保持兼容。
