# 品牌适配与公共边界

## 依赖方向

main.cjs 组装窗口、IPC 和服务。提取服务选择品牌适配器，调用自包含页面脚本，再将解析结果交给公共关系整理。公共导出、存储和界面使用 schema 2 数据，不访问品牌原始 params 或 generationDraft。

LibTV、即梦、RHTV、TapNow 品牌目录不互相导入。共享服务可以影响所有品牌，因此其改动需运行各品牌回归；品牌规则变更应限制在自身目录。LibTV 的 generationDraft 兼容分支保留旧输入行为，不导入即梦解析器。

## 新增品牌

1. 新建 src/platforms/<id>/metadata.cjs，定义稳定 id、显示名、适配器版本、首页、作品域名、框架域名、允许跳转域名、能力与加载策略。
2. 提供 index.cjs，导出 page.readCanvas、page.inspectWork、page.openCanvas、inspectAccount、parseGeneration、cleanText、textFields、collectAssets、describeAsset、preview、isResource、isCanvasUrl、leftWork。
3. 在 registry.cjs 添加一个 metadata/load 注册项。只提前加载元数据，复杂解析代码在首次使用时加载。
   可选的 validateWorkUrl(url) 在建立读取任务前校验作品路径；TapNow 用它拒绝列表页，避免误开推荐作品。
4. 增加该品牌真实结构的脱敏夹具、裸页面注入测试、解析与统一模型测试，以及 Electron 合成页面流程验证。

账号入口、品牌选择、账号管理和公共业务流程使用平台注册信息，无需修改各处品牌名单。新增品牌应先完成基础字段与只读能力，再补全素材能力，不能假设所有品牌采用 React Flow 或同一生成参数格式。

## 注入约定

页面函数通过 toString() 序列化后在页面中执行。函数体只能使用页面提供的 DOM/状态和明确参数，不能引用应用侧 import、require、变量或闭包。必要的页面辅助逻辑放在注入函数内部；宿主辅助逻辑留在适配器其他模块。

readCanvas 返回 found、source、frameUrl、nodes、edges、mediaResources 及可获取的声明计数。当前内置读取器会将自身平台格式转换成此快照；新品牌可以使用不同读取策略，保持输出边界稳定。

parseGeneration 返回 kind、prompt、references、settings、model、promptSource、extra、explicit、warnings。引用必须保留直接参数证据与连线证据的区别。collectAssets 通过公共 add 接口提供媒体描述；公共层负责去重、稳定标识、文件名及下载状态。

## 项目和任务

schemaVersion 2 保持不变，应用和适配器版本是附加元数据。旧 brand id 不改名；本地格式校验不依赖当前品牌注册列表。适配器未安装时仍可读离线项目，但不能重新在线提取。

读取器可返回稳定的 `workIdentity`；规范化将其存入项目元数据，项目存储优先使用该标识建立索引。保留这一公共字段以兼容已保存项目；未提供标识的平台继续使用原有索引方式，schema 2 不变。

TaskScope 管理单个提取任务、递增标识和取消信号。不同任务之间不复用提交权；界面拒绝过期标识。媒体 fetcher 在创建时捕获品牌会话与 Referer，媒体协议捕获项目上下文并监听取消信号。

完整性有 complete、partial、unverified 三态。计数一致不能证明历史生成来源；不支持的节点、正文或富文本片段必须保留诊断。浏览器内部组件结构变化仍需要更新相应品牌读取器。
