# NeoWow · v1.4 接入说明

本次在现有项目目录升级到 1.4.0，继续使用当前 `.runtime/profile`，保留原有登录和偏好；不迁移或读取 Chrome 的登录凭据。

## 已实现

- 注册 NeoWow 网站入口和独立 `persist:neowow` 登录分区；网站访问、画布读取及媒体下载共用此分区。
- 支持 `/video-works-view?id=…`、`/video-works-view?sessionId=…`、`/workflow?sessionId=…`、`/ai-workflow?sessionId=…` 和 `/workflows?shareCode=…`。首页和列表页要求提供具体作品链接。
- 从生产 Vue 组件树读取 VueFlow 的完整 nodes / edges，包括屏幕外节点。只复制内容白名单，排除账号字段、函数、历史列表及连线运行时对象。
- 保留文本正文、媒体生成提示词、音频专用提示词、模型、视频通用模式参数、参数引用顺序、分组与连线。输入文本快照与当前正文不一致时分别保留。
- 识别同一媒体在 NeoWow 两个已知 CDN 域名下的别名，避免制造错误的来源节点匹配；排序列表中的已删除引用不会重新进入下载队列。
- 复用现有 Markdown/TXT 保存、素材下载和 schema 2 离线重开。具体作品 ID 参与项目标识，避免详情页共用路径造成覆盖。
- 普通赠礼弹窗仅点击关闭；登录、缺少创作过程、需要赞赏时给出明确说明。只检查创作过程已有访问权限，不自动支付、复制、生成或发布。
- 支持 `/creator?userId=…` 作者主页：保留长整数编号为字符串，使用同站只读作者资料和作品分页接口，仅读取作品栏目；置顶重复项按作品编号去重，同名作品或共用画布的作品分别保留。
- 复用作者选集的勾选、批量读取、停止、失败重试、每作品保存、作者项目索引及离线恢复。列表读取不会自动提取画布；明确未公开的作品仅保留已发布视频，权限未知项继续由作品读取器确认。
- 未知的导演台、3D 世界等节点保留完整性诊断。
