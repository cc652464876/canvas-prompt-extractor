# 开发与验证

这是 v1.0.0 源码。`src/` 为程序及平台适配代码，`scripts/` 为构建和验证工具，`tests/` 为单元测试。已登录的浏览器资料、用户导出、测试快照和本地历史版本不随仓库提供。

在 Windows x64 上安装 Node.js，运行 `npm install` 获取固定版本 Electron 44.5.1。使用 `npm start` 启动；`npm test` 运行单元测试；`npm run build` 执行构建检查；`npm run package:portable` 生成 `dist/` 下的便携目录和 ZIP。构建脚本也支持 `--runtime <Electron运行时目录>`。

部分历史 UI/视频验证脚本引用上级目录的开发运行时、历史版本示例素材或本地 `validation/` 快照。这些私有测试资料不随仓库分发，相应脚本需要自行提供夹具；不应把用户资料提交到仓库。自包含的单元测试无需个人登录资料。

v1.0 发布前已完成 90 项单元测试、16 组回归、5 组主题验证和 63 个脚本语法检查。最终 ZIP 验证了 EXE/CMD 独立启动、偏好恢复和程序目录移动，以及 LibTV 公开示例读取。即梦真实登录画布、全部素材 CDN、其他电脑的兼容性尚未完整验证。

运行时和程序源码由白名单打包。程序首次运行才在 EXE 旁创建 `.runtime/`。发布时使用干净构建产物，不能重新压缩包含用户会话的运行目录。仓库中的演示截图取自合成数据验证，不含个人账号或私人作品。
